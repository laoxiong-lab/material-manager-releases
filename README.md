# 老熊素材管理器

面向 Windows 的本地素材管理工具，支持文件夹浏览、搜索、收藏，以及图片、视频、音频和 FLA 等素材的预览。

素材保留在原来的文件夹中，索引和预览缓存保存在本机。

## 发布状态

本仓库用于发布软件和使用说明，不发布管理器业务源码。目前尚未发布可下载的安装包。

安装包发布后，可在 [Releases](https://github.com/laoxiong-lab/material-manager-releases/releases) 页面获取。

## 下载与安装

安装包发布后，请从 Releases 选择以 `.exe` 结尾的安装包下载并运行。后续若同时提供 `.blockmap` 和 `latest.yml`，这些文件由软件更新程序使用，无需手动打开。

更新前请正常退出素材管理器，再运行新版安装包。保持原有安装和数据目录，可继续使用已有索引、收藏与预览缓存。更新前建议备份重要数据。

## 使用说明

1. 个人用户可按 LICENSE 免费安装和使用；企业、工作室、机构等组织及其他非个人使用者，应先取得书面授权。
2. 安装并启动软件。
3. 点击“添加素材库”，选择存放素材的文件夹。
4. 等待扫描后，即可浏览、搜索、收藏和预览素材。

生成新的 FLA 预览需要本机安装合法授权的 Adobe Animate，当前适配 Animate 2023；生成时可能启动 Animate。已有预览缓存可以直接显示。

不使用 FLA 预览功能时，无需为此安装 Animate。复杂或较大的 FLA 生成预览可能需要较长时间。
